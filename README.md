# ☁️ WeatherNow

A cute and aesthetic weather forecasting web application built using Java and Spring Boot.

### 🌸 Live Demo

**[Visit WeatherNow](https://weathernow-18qx.onrender.com)**

Search for any city and explore its current weather and 5-day forecast.

### ✨ Features

- Search weather by city name.
- View current temperature.
- Check feels-like temperature.
- View humidity and wind speed.
- Get a 5-day weather forecast.
- Dynamic weather icons.
- Responsive and aesthetic user interface.

### 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/shubhaa-15/WeatherNow.git
```

2. Navigate into the project:

```bash
cd WeatherNow
```

3. Set your OpenWeatherMap API key in PowerShell:

```powershell
$env:WEATHER_API_KEY="your_api_key"
```

4. Run the application:

```powershell
.\mvnw.cmd spring-boot:run
```

5. Open your browser:

```text
http://localhost:8080
```

### 🔑 Environment Variable

The application requires:

```text
WEATHER_API_KEY
```

Get your API key from OpenWeatherMap.
